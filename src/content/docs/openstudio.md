Thelia est développé et maintenu par [OpenStudio](https://www.openstudio.fr). Cette académie est écrite par la même équipe, à partir du code et des écrans du logiciel.

## Un logiciel libre, chez vous

- Thelia est distribué sous licence libre GPL v3. Le code est public, vous pouvez le lire et le faire évoluer.
- Le logiciel ne coûte rien : pas de licence à payer.
- La boutique s'installe sur le serveur de votre choix. Les données de vos clients et de vos commandes restent chez vous.

## L'IA, avec le fournisseur que vous choisissez

Les fonctions d'IA du cœur de Thelia passent par une connexion que vous réglez dans le back-office. Vous y branchez le fournisseur que vous voulez :

- des services français : Mistral, Scaleway, OVHcloud, ou Albert, le service d'IA de l'État ;
- un modèle installé sur vos propres serveurs, avec Ollama ;
- OpenAI ou Anthropic, si vous le décidez.

## Être accompagné

OpenStudio accompagne les marchands et les agences qui travaillent avec Thelia :

- mise en place et évolution de la boutique ;
- formation des équipes, en s'appuyant sur cette académie ;
- choix d'un hébergement et d'une IA souverains.

[Contacter OpenStudio](https://www.openstudio.fr)

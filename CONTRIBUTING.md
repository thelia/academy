# Contributing

Thank you for helping merchants learn Thelia.

- A tutorial covers one task a merchant does in the back office or on the store.
- Write the French page first; the English page translates it.
- Read the [style guide](docs/style-guide.md) (French) before writing. Every statement must be checked against the code or a real screen, and listed in the page's `sources`.
- Screenshots come from `npm run capture`, never from a manual screenshot.
- Run `npm run check && npm run build` before opening a pull request.

Found a wrong label or a broken screen? Open an issue with the page URL and what you see in your back office.
